<h2 id="copy-this-view">Copy this view</h2>

"Copy this view" creates a shareable address that reproduces the current state of the Atlas. It includes the selected year, the layers you have added and their order, their visibility settings, the layer currently being inspected, the browsing mode, the selected collection, the year filter and any active facets.

You can paste this address into a message, an essay or a citation so that someone else can open the same view. If your browser does not allow the Atlas to copy the address automatically, the address is displayed in a text field for you to copy manually.

The view is encoded entirely in the address. The Atlas does not save your session in browser storage or maintain a separate record of views. A view you haven't copied isn't kept anywhere.

<h2 id="retired-addresses">Retired addresses</h2>

Layer identifiers sometimes change as research develops and the catalogue is revised. The Atlas handles these changes so that previously shared addresses remain useful wherever possible.

If an address refers to a layer that has since been renamed, the Atlas opens the layer under its current name and displays a notice explaining the change: old-name is now new-name.

If an address refers to a layer that is no longer present in the Atlas, that layer is omitted. The Atlas displays a notice identifying the unavailable layer while continuing to load the rest of the requested view.

The notice reports what could not be resolved, but deliberately does not say why a layer is missing.
