# Archive patch

The frozen terra-chartarum.pages.dev project is labelled as an archive by three files held here (spec 008, FR-004, FR-019). They are applied to the archive project by pull request in its own repository, with the named `archive_patch` sign-off in `docs/cutover.md`.

| File here | Goes in the archive project | Effect |
| --- | --- | --- |
| `banner.html` | Inserted at the top of the `<body>` of the shared page layout, so every page carries it | The "archived edition" notice and the link to https://terra-chartarum.org/. No script. |
| `_headers` | The output root (the folder Cloudflare serves), next to `index.html`; merge with any existing rules | `X-Robots-Tag: noindex` on every path. |
| `_redirects` | The output root; generated by `registry archive-redirects`, never written by hand | One 301 per moved URL; everything else is served in place. |

## Verify

After the archive is deployed, from this repository and by hand (it uses the network):

```
npm run archive:check -- https://terra-chartarum.pages.dev/ <a few old essay URLs>
```

It exits 1 and names the URL and the missing banner, header or link for each failure.
